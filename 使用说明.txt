防缓存版首次安装（必须更换启动文件并重启）
1. 在旧启动窗口按 Control+C，停止旧服务。
2. 解压本包，双击本包里的 start-mac.command（Mac）或 start-windows.bat（Windows）。不要同时运行旧版。
3. 同一台电脑、IP及端口不变时，继续使用原来的访问地址。
4. 已访问过的浏览器首次切换可能需要强制刷新一次：Mac Command+Shift+R，Windows Ctrl+F5。
5. 如需沿用旧文件夹，请同时替换 start-lan.py 和 site 文件夹，然后重新启动服务。仅替换 site 不会启用新的防缓存服务。

防缓存生效后
- 每次打开或刷新页面，服务会返回当前文件；更新后大家正常刷新即可。
- 已打开的页面不会自动刷新，不会打断正在填写的内容。
- 不清除浏览器保存的订单和草稿。
- 以后更新需覆盖实际运行文件夹的 site 内容；启动窗口会显示该文件夹位置。
- 本地/局域网防缓存响应设置由本包启动程序提供。若改用其他服务器或公网代理，需在对应服务上配置缓存策略。

3. 刷新页面；若仍显示旧版，请强制刷新浏览器（Windows Ctrl+F5；Mac Command+Shift+R）。
不要在另一台电脑启动本包后仍使用 192.168.4.44 地址；该地址只指向 192.168.4.44 那台电脑。

1. 将压缩包完整解压到提供服务的电脑上。
2. 该电脑需要安装 Python 3（建议 3.9 或以上），无需安装其他依赖。
3. macOS：双击 start-mac.command；Windows：双击 start-windows.bat。

4. 页面会自动在浏览器打开。本机地址：http://127.0.0.1:8000/

   地址必须使用提供服务的电脑的真实局域网 IP，不能将 127.0.0.1 或 0.0.0.0 发给同事。

局域网访问条件
- 服务默认监听 0.0.0.0:8000，允许其他设备连接。
- 同事的设备需要与提供服务的电脑在同一局域网，或网络之间可以互通。
- 系统防火墙弹出提示时，允许 Python 在专用网络/局域网接收连接。
- 保持电脑开机且启动窗口不关闭。按 Ctrl+C 可停止服务。
- 如公司 Wi-Fi 开启了设备隔离，需要网络管理员允许设备互访。
- 无需 GPT 账号，也不经过 chatgpt.site 的访问入口。

端口被占用时
macOS / Linux：python3 start-lan.py --port 8001
Windows：py -3 start-lan.py --port 8001
同时把分享地址的端口改为 8001。

无法打开时
先在服务电脑访问 http://127.0.0.1:8000/，再用同事电脑打开 LAN address。
如果本机能打开、同事打不开，检查局域网 IP、防火墙与设备隔离。
启动窗口没有 LAN address 时，可在系统网络设置中查看 IPv4 地址。
